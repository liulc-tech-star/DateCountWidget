# 日期计数

安卓应用：在应用里设置一个日期，桌面插件会显示它已经过去或还剩多少周、多少天。

## 功能

- 添加多个日期（纪念日、倒计日都可以）
- 过去的日期：显示已经过去多少周 + 多少天，以及总天数
- 未来的日期：显示还剩多少周 + 多少天，以及总天数
- 显示方式可单独设置：只看周+天、只看总天数、或两者都显示
- 桌面插件：长按桌面空白处 → 微件/插件 → 「日期计数插件」
- 插件最小 2×1，默认 2×2，可再拉大；小尺寸会自动换成更紧凑的显示

## 打开工程

用 Android Studio 打开项目文件夹。

本机需要：

- JDK 17 或更高，并配置 `JAVA_HOME`（或让 Android Studio 使用其内置 JDK）
- Android SDK；Android Studio 会生成本机的 `local.properties`，命令行可设置 `ANDROID_HOME` 环境变量

命令行编译：

```powershell
.\gradlew.bat assembleDebug
```

安装到手机或模拟器：

```powershell
.\gradlew.bat installDebug
```

## 使用

1. 打开应用，点右下角加号，选一个日期并起名。也可以直接把插件放到桌面后再添加。
2. 回到桌面，长按空白处，添加「日期计数插件」，在弹出列表里选一个日期。
3. 之后点插件会再次打开选择页，可以换日期。
4. 新建桌面插件、跨天和打开应用时刷新。编辑日期或给已有插件换日期，不会额外触发刷新；下次打开应用或跨天时显示新内容。

## 刷新规则

- 禁用系统每 30 分钟刷新，移除每小时后台任务。
- 由 WorkManager 安排下一个本地午夜的一次性任务；执行后再安排下一次，不按固定间隔轮询，也不启动常驻服务。
- 每个插件记录上次刷新的本地日期，避免同一天被多个日期变化通知重复刷新；打开应用时允许主动刷新。
- 修改时间或时区时重新计算下一次午夜；本地日期没有变化则不刷新。重启手机、更新应用后恢复调度。
- 移除最后一个插件后取消后台任务；升级时会取消旧版本的每小时任务。
- 午夜任务不是精确闹钟，系统省电限制可能推迟执行，不能保证 00:00 整点更新。
- 插件绑定只保存在一处；Glance 的短期显示会话仅监听有效刷新请求，不持续订阅日期记录变化。

验证：`./gradlew.bat assembleDebug testDebugUnitTest lintDebug`。
